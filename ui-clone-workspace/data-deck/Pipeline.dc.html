How the data is collected
Built to be re-run, not run once. Government data changes; a seed that was true in August is not automatically true in March.
01 Registry One file declares every source: publisher, access route, licence, cadence, tier. No URL is hardcoded anywhere else.
02 Fetch Official API first. Plain HTTP. Never a workaround. Retries with backoff; a failure keeps the last good copy.
03 Manifest Publisher, retrieval date and a SHA-256 per file. A later re-fetch can be proved identical.
04 Cadence Each domain re-checks on its own clock. MSP 90 days · costs 365 · schemes 90 · prices daily.
A re-run that finds nothing changed costs 1.2 seconds and writes nothing. Only a genuine change updates the record of when this last changed.
