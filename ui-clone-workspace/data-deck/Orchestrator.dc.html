Streamlining for the orchestrator 07 / 08
Turning cluttered data into a decision
Four rules stand between raw public data and anything the orchestrator is allowed to say.
Rule 01 Names are mapped, never guessed One table maps every source's vocabulary into ours. An unrecognised name stops the run. Fuzzy matching would fold Paddy (Grade A) into Paddy (Common) — two different prices, one silent error.
Rule 02 Disagreement is shown, not settled When two sources conflict beyond tolerance, both claims are kept and confidence drops. The system never quietly picks a winner and presents it as the answer.
Rule 03 Unsourced crops leave the comparison A margin ranking admits a crop only when every cost behind it is sourced. Margin is a difference of two numbers — an invented cost can win on the strength of the invention.
Rule 04 Guidance cannot outrank a survey Advisory material informs suggestions. It never competes in a ranked result. A confident single-district study must not outrank a 900-farmer state survey.
What reaches the FPO is not "the data we found". It is what survived four rules designed to catch the plausible wrong answer — the kind that never announces itself.
