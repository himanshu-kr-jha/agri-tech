The problem 02 / 08
Public data is abundant. It is not usable.
285,974 datasets on the national open-data portal Abundance is not availability. Most are irrelevant, superseded, or one row of nothing.
3 names for one crop, across three government sources R & M · Rapeseed/Mustard · Mustard — and none of it is derivable.
0 rows returned for the district the FPO actually farms The series predates the 2018 rename. PRAYAGRAJ matches nothing; ALLAHABAD matches 470.
9 of 10 sources whose licence is not stated anywhere Usable for research. Not automatically usable in a product.
Every one of these failures is silent. Each returns a plausible answer rather than an error — which is what makes them dangerous in a system that advises farmers.
